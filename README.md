# Digital Image Processing App

Modern image processing web application built using Streamlit and OpenCV.

## Features

- Multiple Filter Stacking
- Realtime Preview
- Before / After Slider
- Vintage Filters
- Light Leak Effects
- Brightness & Contrast
- Rotate & Flip
- Download Processed Image

## Technologies

- Python
- Streamlit
- OpenCV
- NumPy
- Pillow
